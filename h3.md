## Can't Fish - Disable Networking and Test

### Steps:
1. Check internet connection: ping 8.8.8.8
2. Identify the network interface in system settings.
3. Disable network: sudo ip link set <interface> down
4. Verify by running ping 8.8.8.8 again.
5. Re-enable network: sudo ip link set <interface> up

### Analysis:
- ping tests if an internet connection is active.
- A disabled network results in no response.
- **Conclusion:** Disabling the network prevents external connectivity.

## Port Scanning - Understanding the Risks

### Steps:
1. Disconnect from the internet.
2. Install Nmap if not already installed:
   sudo apt-get update && sudo apt-get install -y nmap
3. Perform a scan on localhost:
   sudo nmap -A localhost
   
### Analysis:
- nmap scans the **1000 most common ports**.
- -A enables **banner grabbing, OS detection, and script scanning**.
- Scanning only localhost ensures you are not scanning unauthorized systems.
- **Legal Note:** In some countries, port scanning **without permission** is illegal.
- **Conclusion:** Port scanning helps identify security weaknesses but should only be performed on systems you own or have permission to scan.

## Daemon Scan - Installing a Server and Scanning Again

### Steps:
1. Install Apache: sudo apt-get update && sudo apt-get -y install apache2
2. Start Apache: sudo systemctl start apache2
3. Re-run the scan: sudo nmap -A localhost

### Analysis:
- Before installing Apache, only essential services were detected.
- After installation, port 80 is now open for web traffic.
- **Conclusion:** Running server applications increases the system's attack surface.

## Bandit Oh-Five - OverTheWire Levels 0-4

### Steps & Solutions:
1. Connect: ssh bandit0@bandit.labs.overthewire.org -p 2220
2. Level 0 → 1: cat readme
3. Level 1 → 2: cat ./-
4. Level 2 → 3: cat "spaces in this filename"
5. Level 3 → 4: ls -la /inhere/` and `cat /inhere/.hidden
6. Level 4 → 5: file /inhere/* | grep ASCII

### Analysis:
- **Key lessons:**
  - Hidden files can be found using ls -la.
  - Quotes are required for filenames with spaces.
  - The file command helps identify readable text files.
