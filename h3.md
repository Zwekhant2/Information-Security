## Can't Fish - Disable Networking and Test

### Steps:
1. Check if the internet is working:
   ```
   ping 8.8.8.8
   ```
2. Find your network name in system settings.
3. Turn off the network:
   ```
   sudo ip link set <interface> down
   ```
4. Try `ping 8.8.8.8` again—it should fail.
5. Turn the network back on:
   ```
   sudo ip link set <interface> up
   ```

### Analysis:
- `ping` checks if your internet is working.
- If the network is off, there is no response.
- **Conclusion:** Turning off networking blocks internet access.

## Port Scanning - Understanding the Risks

### Steps:
1. Disconnect from the internet.
2. Install Nmap if it’s not installed:
   ```
   sudo apt-get update && sudo apt-get install -y nmap
   ```
3. Scan your own computer:
   ```
   sudo nmap -A localhost
   ```

### Analysis:
- `nmap` looks for open network ports.
- `-A` finds details like running services and OS info.
- Only scanning `localhost` keeps it legal and safe.
- **Conclusion:** Scanning helps find security risks but should only be done on computers you own.

## Daemon Scan - Installing a Server and Scanning Again

### Steps:
1. Install a web server (Apache):
   ```
   sudo apt-get update && sudo apt-get -y install apache2
   ```
2. Start Apache:
   ```
   sudo systemctl start apache2
   ```
3. Scan again:
   ```
   sudo nmap -A localhost
   ```

### Analysis:
- Before Apache was installed, only basic services were visible.
- After installing Apache, port 80 is now open.
- **Conclusion:** Running a server increases open ports and security risks.

## Bandit Oh-Five - OverTheWire Levels 0-4

### Steps & Solutions:
1. Connect to the server:
   ```
   ssh bandit0@bandit.labs.overthewire.org -p 2220
   ```
2. Level 0 → 1: Find the password in `readme`:
   ```
   cat readme
   ```
3. Level 1 → 2: Read a tricky filename:
   ```
   cat ./-
   ```
4. Level 2 → 3: Open a file with spaces in its name:
   ```
   cat "spaces in this filename"
   ```
5. Level 3 → 4: Look for a hidden file:
   ```
   ls -la /inhere/
   cat /inhere/.hidden
   ```
6. Level 4 → 5: Find a readable text file:
   ```
   file /inhere/* | grep ASCII
   ```

### Analysis:
- **Key takeaways:**
  - Hidden files can be found with `ls -la`.
  - Filenames with spaces need quotes.
  - The `file` command helps find human-readable text files.
