### **m) Encrypt and Decrypt Messages Using Another Tool**
- Tool: `age`
- Install age:
  ```sh
  sudo apt-get install age
  ```
- Encrypt a message:
  ```sh
  echo "Secret Message" | age -r <recipient-key> > secret.age
  ```
- Decrypt the message:
  ```sh
  age -d -i <private-key-file> secret.age
  ```
- **Evaluation:** Age is simpler and faster than GPG, especially for file encryption.

### **t)**
- **Could double rot13 provide extra security?**
  - No. Applying ROT13 twice results in the original text.
  - Since ROT13 is just a letter shift, it provides no real security. It's mainly used for obscuring spoilers or jokes.
  - Example:
    ```sh
    echo "Uryyb, Jbeyq!" | tr 'A-Za-z' 'N-ZA-Mn-za-m'
    ```
    Output: `Hello, World!`
- **Why Is ROT13 Not Secure?**
  - It is a simple **Caesar cipher** with a shift of 13.
  - There is no key involved, so anyone can decrypt it easily.
  - It's only useful for hiding text from casual readers, not for real encryption.
