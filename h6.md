### x) Summary of Readings
#### Schneier 2015: Applied Cryptography
**2.3 One-Way Functions:**
- These are functions that are easy to do but very hard to undo.
- They are used in cryptography to keep data safe.
- Examples include multiplying large numbers and using modular math.
- They help with encryption and digital signatures.

**2.4 One-Way Hash Functions:**
- A hash function takes input data and turns it into a fixed-size code.
- It is almost impossible to get the original data back from the hash.
- Good hash functions do not allow two different inputs to have the same output.
- They are used for storing passwords, checking data integrity, and digital security.

### p) Summary of Forbes 2019: Jackpotting ATMs

- Jackpotting is when hackers make an ATM give out cash illegally.
- They install malware or use physical tricks to bypass security.
- Some ATMs have weak security, like old software or no encryption.
- The attack was shown at Disobey 2019 to raise awareness of security risks.
